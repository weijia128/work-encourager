# 上班鼓励器 设计文档

日期：2026-11-04
状态：已过构建者检查，待用户确认

## 1. 这是什么，为什么做

这是一个常驻桌面的小程序，用来提醒自己"上班的每一秒都在赚钱"。灵感来自抖音上流传的"上班鼓励器"，那个程序会显示今日已赚、每秒速度、下班倒计时，还有"再过 X 小时，一件 T 恤就赚回来了"这样的文案。

在它的基础上，这个版本的不同之处：

- **把上班当成一笔投资来比**。"本月上班进度"（本月已赚 ÷ 满勤月薪）就是"我"这个月的收益率，和沪深300、科创50、黄金等品种的本月涨跌幅放在一起看。大部分时候"我"都是赢的，这正是乐趣所在。
- **更有仪式感**：有今日进度条、本月进度条、轮换的趣味文案，还有一个可以点的电子木鱼（功德 +1）。

**用户和目标**：先给作者本人用，作者用 Mac 为主。如果反响好，再考虑当副业推广，所以 Windows 版从一开始就要能出包。

**成功标准**：作者愿意每天开着它，连续用一个月不嫌烦也不嫌丑。

## 2. 目标 / 非目标 / 反目标

**目标**
- Mac 和 Windows 两个平台都能用，一套代码。
- 按设定的作息自动切换状态，不需要每天手动操作。
- 本月收益率可以和用户自选的品种对比。

**非目标（v1 不做）**
- 请假、加班、迟到、扣款、调休补班的个人化处理。**一律按全勤算**：只要是工作日的上班时间，就是纯赚。
- 生成分享战报图片（以后做副业时再考虑，可以参考"一对一对决"的样式）。
- 期货品种（换合约会导致月涨幅失真，等真想要了再加）。
- 接大模型生成文案。
- 账号、云同步、多设备。
- 小程序或手机版。

**反目标（做出来了但出现这些就算失败）**
- 打扰人：除了月初一次"本月设置有变化吗"的确认，不弹任何窗口，也没有通知轰炸。
- 看起来像炒股软件或者给投资建议。它只是"拿上班跟行情比着玩"。
- 设置复杂到要看说明书。
- 为极少数特殊作息（轮班、弹性工时、一天两段以上的上班时间等）增加复杂度。目标用户是作息规律、天天开电脑的上班族，特殊情况先不考虑。

## 3. 用户已确定的设计

### 3.1 形态

- **Mac 菜单栏**常驻显示 `💰 ¥79.20`，实时跳动。点击后弹出或唤回完整面板。
- **Windows 托盘**：托盘图标不能显示文字，所以鼠标悬停时用 tooltip 显示今日已赚，点击打开完整面板。
- **桌面悬浮完整面板**：可以选择置顶。关闭面板只是隐藏，程序继续在后台运行，菜单栏或托盘的数字照常更新。
- 只有完全退出程序以后，才需要用户手动重新打开。电脑一般不关机，程序一直挂着。

### 3.2 自动状态切换（没有开始和停止按钮）

| 状态 | 什么时候 | 显示 |
|---|---|---|
| 还没上班 | 工作日、上班时间之前 | 距离上班还有 X；今日已赚 ¥0 |
| 上班中 | 工作日、上班时段内（不含午休） | 每秒跳钱、距离下班倒计时 |
| 午休中 | 工作日午休时段 | 今日已赚暂停；距离午休结束 X |
| 已下班 | 工作日、下班时间之后 | 今日已赚定格在满勤日薪 |
| 休息日 | 周末、法定节假日 | "今天休息"；显示本月已赚 |

- **不设"关闭计时器"按钮**。
- 全部按真实时钟实时计算，所以电脑睡眠或合盖不影响结果，唤醒后数字直接对上。

### 3.3 收入怎么算

- 日薪 = 月薪 ÷ 当月实际工作日数（按休息制度和法定节假日算）。这样本月进度到月底正好是 100%。
- 每秒速度 = 日薪 ÷ 每日有效工作秒数（上下班之间的时长减去午休）。
- 今日已赚 = 每秒速度 × 今天已经工作的有效秒数。
- 本月已赚 = 本月已过工作日数 × 日薪 + 今日已赚。
- **本月进度（"我"的收益率）**= 本月已赚 ÷ 月薪。
- 时薪 = 日薪 ÷ 每日有效工作小时数。

### 3.4 完整面板内容（按从上到下的顺序）

参照已确认的 mockup：`.superpowers/brainstorm/*/content/panel-v2.html`。

1. 标题栏：💰 上班鼓励器、⚙ 设置
2. 日期、星期、时间（精确到秒）
3. 状态，加上距离下班或上班的倒计时
4. **今日已赚**：大号数字，保留 4 位小数，每秒跳动
5. 每秒速度、时薪
6. **一条趣味文案**（见 3.6）
7. **今日进度条**：百分比，以及已工作小时数 / 每日小时数
8. **本月进度条**：百分比、本月已赚 / 月薪、"第 N/M 个工作日"
9. **品种小标签**：每个品种显示"名称 + 本月涨跌幅"，红涨绿跌（A 股习惯）；最后一个是"＋"添加按钮，可以删除已有品种
10. **功德木鱼**：点击后显示"功德 +1"的飘字动画，记录今日功德和累计功德

### 3.5 行情对比

- 默认品种：沪深300、科创50、黄金（上金所 Au99.99，或者黄金 ETF 518880，由构建者选数据更稳的那个）。
- "＋"添加：按名称或代码搜索，支持 **A 股指数、ETF、个股**。
- 本月涨跌幅 = 最新价 ÷ 上月最后一个交易日收盘价 − 1。
- 刷新频率：交易时段每几分钟刷新一次；收盘后和休市日不刷新，显示最近一次的值。
- 拉取失败时显示上次缓存的值，并在旁边做一个不显眼的"数据未更新"标记，**不弹窗**。
- 数据源：新浪、腾讯、东方财富的免费公开接口。这些不是官方开放接口，自用没问题；**以后做成副业分发时，要换成有授权的数据源**（比如 Tushare 或 iFinD），所以数据获取要封装在一个可替换的模块里。

### 3.6 趣味文案

全部在本机按规则生成，不联网，不接 AI。三种来源轮换显示：

1. **物品库**：内置几十种常见物品和价格（瑞幸 ¥15、外卖 ¥30、T 恤 ¥99、电影票 ¥45……）。程序选出"今日已赚还没够的下一个物品"，输出"再过 {剩余时间}，{物品} 就赚回来了"。
2. **心愿单**：用户在设置里添加想买的东西和价格，输出"本月已经赚出 {N} 个 {心愿}"。
3. **时段和行情文案**：按状态或时间触发，比如"坚持住，还有 12 分钟开饭""最后 30 分钟，每一秒都是纯赚""今天上班又跑赢了科创50"。

### 3.7 设置

- 第一次打开时引导填写：
  - **称呼**：之后的界面和文案都带上称呼，比如“小叶，上班中”“小叶，再过 23 分钟，一杯瑞幸就赚回来了”，显得更亲近
  - 月薪
  - 上班时间、下班时间、午休开始和结束时间
  - 休息制度：双休、单休或大小周（大小周需要指定本周是大周还是小周）。**三种都是 v1 必做，而且同等重要**：用户群体是作息规律的上班族，每个人的制度和工时都不一样，所以都在初始化里由用户自己选、自己填
  - 关注品种
  - 心愿单（可以不填）
  - 是否开机自启（默认关）
  - 面板是否置顶
- 法定节假日和调休补班日自动按国家日历处理，用户不用管。
- **每个月第一个工作日**，第一次进入上班状态时，在面板内提示一次"本月设置有变化吗？"，可以直接确认，也可以去改。不用系统弹窗。
- 所有设置和功德计数都只存在本机。

## 4. 我替用户定的（可以改）

- **技术方案**：Tauri 2，一套代码打包 Mac 和 Windows，安装包小，原生支持菜单栏和托盘。用户主要靠 AI 写代码，这个技术栈对 AI 很友好。
- **不做小程序**：小程序没法常驻屏幕，而且展示证券行情需要资质，个人主体基本拿不到。
- 日薪按"当月实际工作日数"来分摊（见 3.3）。
- 品种小标签用 A 股的红涨绿跌配色。
- 木鱼**默认静音**，在设置里可以打开敲击音效，免得办公室里突然响起来。
- 开机自启默认关闭。
- **休息制度和法定节假日叠加的规则**：
  - 法定节假日一律休息，调休补班日一律上班，优先级高于休息制度。
  - 单休固定周日休息。
  - 大小周：小周周六上班。大小周按自然周连续交替，不因为节假日重置。
- **月初提示没人看见怎么办**：面板不自动弹出。菜单栏或托盘图标上加一个小红点，等用户下次打开面板时显示提示，确认后红点消失。
- **v1 发布范围**：不做代码签名和公证，也不做自动更新。Mac 版在本机构建；Windows 版通过 GitHub Actions 出未签名的安装包，**由作者在家里的 Windows 电脑上实际安装验证**（办公室没有 Windows，验证要安排在下班后做）。签名、公证和正规分发留到做副业时再说。

## 5. 留给构建者决定

- 前端框架和 UI 实现细节（遵循 mockup 的信息层级和气质即可）。
- 具体用哪个行情接口、怎么解决跨域（比如在 Rust 侧请求，或者用 Tauri 的 http 插件），以及刷新间隔。
- 节假日数据怎么获取和更新（比如内置 holiday-cn 这类开源数据，每年更新一次）。
- 物品库和文案库的具体内容、轮换频率。
- 本地存储方式。
- 应用图标、菜单栏显示几位小数。
- 测试：收入计算、工作日计算、本月涨跌幅计算都应该是纯函数，并且要有充分的单元测试（用户的规范要求覆盖率 80% 以上）。
